# Análise Exploratória e Tratamento de Dados: Pesquisa Data Hackers 2022

## 📝 Sobre o Projeto
Este projeto consiste no tratamento e análise exploratória dos dados da pesquisa anual realizada pela comunidade **Data Hackers** em 2022. O objetivo principal foi aplicar técnicas fundamentais de manipulação de dados em Python, estabelecendo uma base sólida de conhecimento necessária para o desenvolvimento de soluções robustas em **Inteligência Artificial** e **Engenharia de Dados**.

A análise foca em entender o panorama do mercado de tecnologia no Brasil, com um olhar detalhado sobre tendências salariais, tecnologias mais utilizadas e indicadores de diversidade no setor.

## 🧠 Objetivos Técnicos
Para construir modelos de IA eficazes, o primeiro passo é o domínio sobre a qualidade dos dados. Neste projeto, foquei em:
* **Data Wrangling:** Limpeza de dados brutos e tratamento de valores ausentes (NaN).
* **Padronização:** Transformação de variáveis categóricas e normalização de dados para análise.
* **EDA (Exploratory Data Analysis):** Identificação de padrões, outliers e correlações entre variáveis socioeconômicas e profissionais.

## 🛠️ Tecnologias e Ferramentas
* **Linguagem:** Python
* **Ambiente:** Google Colab
* **Bibliotecas:** * `Pandas` para manipulação e estruturação dos dados.

## 📊 Principais Insights
* **Mercado de TI:** Identificação das habilidades técnicas mais demandadas e sua relação com a remuneração.
* **Diversidade e Inclusão:** Análise da representatividade de gênero e raça no cenário tech brasileiro, destacando os desafios e lacunas existentes.
* **Fundamentos para IA:** A estruturação desta base de dados foi pensada para facilitar futuros processos de modelagem preditiva e aprendizado de máquina.
